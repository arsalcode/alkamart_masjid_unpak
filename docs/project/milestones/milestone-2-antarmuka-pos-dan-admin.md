# 🎯 Milestone 2: Pengembangan Antarmuka POS Kasir & Dashboard Admin
**Target Waktu**: Minggu 2
**Status**: Selesai (Completed ✅)

---

### Tujuan:
Membangun antarmuka pengguna (UI/UX) berbasis HTML5, CSS3 murni dengan tema hijau Alkamart (#2E7D32), responsif untuk smartphone kasir maupun monitor PC.

---

### Rincian Tugas & Deliverables:
- [x] **Katalog Produk Interaktif**: Grid produk dinamis dengan foto produk, nama, harga, status stok, dan fallback emoji jika gambar tidak tersedia.
- [x] **Pencarian Cepat & Kategori**: Search bar instan, dukungan keyboard Enter / Barcode scanner, dan filter kategori (Makanan, Minuman, Snack, Lainnya).
- [x] **Keranjang Belanja POS**: Kontrol kuantitas instan (+ / -), fitur klik angka kuantitas untuk ketik langsung jumlah banyak, kalkulasi subtotal dan grand total secara real-time.
- [x] **Kalkulasi Pembayaran & Uang Kembalian**: Tombol nominal cepat (Uang Pas, 10rb, 20rb, 50rb, 100rb), kalkulator uang kembalian otomatis, dan pencegahan error nominal kurang.
- [x] **Audio Feedback POS**: Efek suara beep web audio saat barang masuk keranjang dan saat pembayaran sukses.
- [x] **Struk Nota Kasir**: Format nota thermal standar 58mm/80mm siap print fisik ke printer kasir Bluetooth atau kirim nota digital ke WhatsApp pembeli.
- [x] **Dashboard Admin**:
  - Manajemen Produk: Tambah barang baru, edit harga/nama, hapus barang.
  - Upload Foto dari HP: Kamera/galeri HP dengan kompresi otomatis ke Base64 (max 350px).
  - Restok Cepat: Peringatan stok menipis (<= 5 item) dan tombol penambahan stok instan.
  - Rekap Pendapatan: Kalkulasi omzet total, jumlah transaksi, rata-rata belanja, dan tabel riwayat transaksi kasir.
