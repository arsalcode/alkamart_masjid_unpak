# 🎯 Milestone 1: Fondasi, Riset & Spesifikasi Sistem
**Target Waktu**: Minggu 1
**Status**: Selesai (Completed ✅)

---

### Tujuan:
Membangun fondasi analisis kebutuhan, spesifikasi teknis (PRD, SRS, SDS), dan arsitektur data tanpa ketergantungan layanan berbayar atau batasan kuota ketat (menghindari limit Firebase).

---

### Rincian Tugas & Deliverables:
- [x] **Product Requirements Document (PRD)**: Menentukan target pengguna (Admin Pemilik Warung & Karyawan Kasir), visi zero-installation, dan kemampuan berjalan di semua tipe browser HP/PC.
- [x] **Software Requirements Specification (SRS)**: Menentukan kebutuhan fungsional (FR-01 s/d FR-14) meliputi fitur POS kasir, keranjang belanja, kalkulasi kembalian, pemotongan stok otomatis, cetak struk nota, dan rekapitulasi omzet.
- [x] **System Design & Specification (SDS)**: Merancang arsitektur Single Page Application (SPA), skema data JSON produk, keranjang, dan histori transaksi.
- [x] **Arsitektur Penyimpanan Zero-Limit**: Menetapkan penggunaan LocalStorage sebagai database lokal dan Google Sheets sebagai database online gratis tanpa batasan kuota baca/tulis harian.
